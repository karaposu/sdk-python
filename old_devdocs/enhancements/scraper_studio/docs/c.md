# Self Healing Tool - AI Code Refactor

> Use the Self Healing Tool to automatically update and fix your data scraper's code with AI assistance. Easily add or modify input/output fields and resolve broken code.

## What does this tool do?

The AI Code Refactor tool automatically edits your collector's code using AI to modify input or output fields or fix broken code. It intelligently adjusts your existing code by adding/removing fields and making other necessary updates.

## How to use:

1. Enter your request as a prompt in the input field.

   ```text Sample prompts: theme={null}
     Add 'price' and 'image' fields to the output
     The 'price' value is returning 'undefined', please fix
   ```
2. Once the code is generated, review the proposed changes in the template.
3. Accept or decline the changes.
4. After accepting the changes, they will be saved to Development mode.
5. Run a Preview to make sure you are getting the required data.
6. Save the scraper to production.

## Best for:

* Users who need to modify collectors quickly without deep coding knowledge
* Developers looking to save time on routine code adjustments
